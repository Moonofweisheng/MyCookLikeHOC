## Purpose

为菜谱浏览应用提供安静、统一且能表达内容结构的加载占位体验，降低现有彩色渐变、纹理和重复描边对用户造成的视觉噪声，并保证 H5 与微信小程序表现一致。

## ADDED Requirements

### Requirement: 骨架屏使用统一的低对比度视觉语言

骨架屏 MUST 使用与应用暖纸张色板协调的低对比度中性色和单一浅色高光，不得以黄、蓝、绿混合渐变作为默认占位背景；骨架屏内部 MUST 不显示网格纹理，且占位块的描边不得与外层插画卡片形成不必要的重复粗边。

#### Scenario: 页面进入加载状态

- **GIVEN** 首页、分类、搜索或菜谱详情正在请求数据
- **WHEN** 用户看到对应骨架屏
- **THEN** 骨架屏整体与暖纸张页面背景和插画卡片相协调
- **AND** 用户不会看到黄蓝绿混合渐变或密集网格纹理造成的彩色噪声

#### Scenario: 骨架屏位于粗描边卡片内

- **GIVEN** 文字或图片占位位于带有插画粗边框的卡片内部
- **WHEN** 卡片进入加载状态
- **THEN** 占位区域的层级清晰可见
- **AND** 占位块不会因为自身深色描边与外层卡片描边叠加而显得线条过密

### Requirement: 骨架屏支持按内容语义表达占位

通用骨架屏 MUST 支持至少文字、图片和头像/图标三类语义表现；各页面骨架组件 MUST 根据最终内容结构选择对应语义，而不是所有区域使用完全相同的占位样式。

#### Scenario: 菜谱图片加载中

- **GIVEN** 菜谱封面或详情主图尚未加载完成
- **WHEN** 用户看到图片占位
- **THEN** 占位区域保持稳定的图片容器尺寸和圆角
- **AND** 其颜色层级接近现有图片占位色，不呈现为文字条或高对比装饰块

#### Scenario: 文字和头像同时加载中

- **GIVEN** 详情页或分类区域同时等待标题、描述和头像/图标内容
- **WHEN** 用户看到骨架屏
- **THEN** 标题和描述表现为低对比度文字条
- **AND** 头像/图标表现为独立且适配其形状的占位

### Requirement: 加载动效保持轻量且跨端一致

骨架屏 MUST 保留可感知但低干扰的加载动效；动效 MUST 使用低对比度单色高光移动，周期应避免过快闪烁，并在 H5 与微信小程序中保持相同的视觉语义和稳定尺寸。

#### Scenario: 加载持续超过一个动效周期

- **GIVEN** 网络请求持续时间超过骨架屏动效的一个周期
- **WHEN** shimmer 动效重复播放
- **THEN** 高光移动连续且不产生明显色带跳变
- **AND** 骨架块的尺寸、布局和文字占位长度保持不变

#### Scenario: H5 与微信小程序渲染骨架屏

- **GIVEN** 相同页面分别运行在 H5 和微信小程序
- **WHEN** 页面处于加载状态
- **THEN** 两端均展示相同的语义变体、主要颜色层级和动效节奏
- **AND** 不依赖仅浏览器可用的 CSS 选择器或 API
