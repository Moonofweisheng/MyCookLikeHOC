# 饭后分工插画资源规范

- 角色统一使用 `160 × 160` 透明画布，道具使用紧凑透明画布。
- 主描边使用 `#2f2f2d`，角色外轮廓线宽以 `7-9` 为主，端点和连接处使用圆角。
- 填充优先复用 `#83c63f`、`#ffd95c`、`#88c9ff`、`#ef7668`、`#c5a4f3`、`#f2a85c` 与暖纸色 `#fffef9`。
- 文件不包含文字、远程图片、脚本、CSS 动画、滤镜、噪声或复杂遮罩；昵称与状态由页面组件绘制。
- 生产动画只作用于 SVG 外层容器，保证 H5 与微信小程序使用相同资源。
- 命名采用 `buddy-<role>.svg`、`plate-<state>.svg` 和清晰的道具名；未使用的概念图不进入本目录。

## 资源清单与体积基线

- 8 个角色 SVG：`characters/buddy-*.svg`。
- 2 个餐盘状态：`plate-dirty.svg`、`plate-clean.svg`。
- 2 个动效道具：`sponge.svg`、`water-swoosh.svg`。
- 当前 12 个生产 SVG 合计约 `8.1 KiB`（2026-08-19 文件内容统计）；不引入位图、字体、Lottie、Rive、视频或序列帧运行时。
- 微信小程序端通过普通 `<image>` 引用，路径统一以 `/static/dish-duty/` 开头；资源自身不承担动画，缩放和旋转仅作用于外层视图。
